How to read this

Strategy is how often each hand takes each action. Click an action to see how the next player responds.

EV is chips won, counted from the start of the river, so it includes each player's share of the pot. Heads-up, the two EVs add up to the pot. After you put chips in, folding shows as losing them.

Indifference. At equilibrium, a hand that mixes between actions gets the same EV from each of them. In the AAA22 game, 33 bluffs and checks at the same EV, and 88 calls and folds at the same EV.

Could gain is how many chips a player would win by switching to the best counter-strategy. Close to zero means the solve has converged. With three or more players CFR isn't guaranteed to converge, but this number shows how close each player is.

Limits: one effective stack for everyone (no side pots), and every player uses the same bet sizes.
